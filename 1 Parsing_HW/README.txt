Это простой парсер на Python для сбора данных первых трёх страниц каталога интернет-магазина книг.
Для каждой книги извлекается: порядковый номер, название, цена и рейтинг, а затем данные сохраняются в CSV файл.
Необходимые библиотеки:
BeautifulSoup4 — для парсинга HTML,
requests — для HTTP-запросов,
Pandas — для работы с табличными данными.
